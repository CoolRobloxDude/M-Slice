## Introduction

Welcome to **M-Slice**, a Friday Night Funkin' engine based on Psych Engine 1.0.4, combining features from P-Slice, H-Slice and JS Engine.

M-Slice also retains H-Slice's performance optimizations.

## Getting Started

Pre-built builds will be available in [GitHub Actions](https://github.com/CoolRobloxDude/M-Slice/actions).

## Building

### Dependencies

- Git
- Haxe 4.3.6 or greater
- Microsoft Visual Studio Community (Windows)
- VLC (Linux)

Run the setup script in the `setup` folder:

- `Windows.bat` for Windows
- `Unix.sh` for Mac/Linux

Then build with:

```sh
lime test windows
```

Replace `windows` with `linux` or `mac` for other platforms.
